What Color Is This?

Pick a color, type a code, or click a pixel in your own image to find its closest name and values.

How this color name finder works

Enter a color or click a pixel in an uploaded image, and the tool compares it with the 148 standard CSS color names (such as steelblue, tomato and seagreen) and shows the closest match. It also lists the HEX, RGB and HSL values and a color family such as "dark blue" or "light red".

Find the color in an image

  1. Click "Choose file" and select a photo, logo or screenshot.
  2. The image appears below. Click any pixel.
  3. Read the name and copy the HEX value for use in your design.

The image stays in your browser and is never uploaded. Because photos have shadows and noise, a single pixel can differ from the color you expect, so click a few spots.

Why "closest" and not "exact"?

There are about 16.7 million possible RGB colors but only 148 CSS names. Most colors therefore have no exact name, so the tool shows the nearest one by color distance, along with three other close names. If the color is an exact match the result says "Exactly".

Frequently asked questions

How do I find the name of a color?

Enter its HEX or RGB code, use the picker, or click a pixel in an image. The tool shows the closest of the 148 standard CSS color names.

Can I get a color from an image?

Yes. Upload an image and click any pixel. The image is processed in your browser and never uploaded.

Why does it say "closest" instead of an exact name?

Only 148 colors have standard names, while there are over 16 million RGB colors, so most colors are matched to the nearest name.

What is the difference between HEX and RGB?

They describe the same color in different notation. #267FD9 and rgb(38, 127, 217) are identical.

Does it work for paint or Pantone colors?

No. It uses CSS color names for screens. Paint and Pantone systems need their own references.
