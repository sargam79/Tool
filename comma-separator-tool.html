Comma Separator Tool

Paste a column from Excel or a list of items and turn it into a comma-separated line, or the other way round.

How to turn a column into a comma-separated list

  1. Copy a column from Excel, Google Sheets or any text and paste it in the box. Each row becomes one item.
  2. Choose how items are joined: comma, comma and space, semicolon, pipe, tab or a custom separator.
  3. Pick extras such as quotes, sorting or removing duplicates.
  4. Copy the result.
Input: apple / banana / cherry (one per line) → Output: apple, banana, cherry

Common uses

  • SQL IN lists: use the SQL preset to get ('apple', 'banana', 'cherry') ready to paste into a query.
  • Email and tag fields: join addresses or tags with commas or semicolons.
  • Code arrays: wrap items in quotes and square brackets for arrays in JavaScript or Python.
  • Row to column: set "Split input by" to commas and "Join with" to new line to turn a comma line back into rows.

Options explained

OptionWhat it does
Trim spacesRemoves spaces at the start and end of each item.
Remove empty itemsDrops blank lines so you do not get double commas.
Remove duplicatesKeeps the first copy of each item (case-sensitive).
Wrap in quotesAdds single or double quotes; quote characters inside an item are doubled.
SortAlphabetical, reverse, or numeric order.

Everything runs in your browser, so lists with private data such as email addresses or customer IDs are never uploaded.

Tips

  • If your data contains commas, such as "Smith, John", choose new lines to split and a different join character like a semicolon or pipe.
  • For CSV files with many columns, use a spreadsheet instead; this tool is for single lists.

Frequently asked questions

How do I convert a column to a comma-separated list?

Paste the column, keep "New lines" as the input separator and "Comma" as the join. The result shows all items on one line separated by commas.

How do I make a SQL IN list?

Click the SQL IN list preset. It wraps each item in single quotes, joins them with commas and puts the whole list in brackets.

Can I convert a comma list back to rows?

Yes. Paste the list, set "Split input by" to commas and "Join with" to New line, or click Back to column after converting.

Does it remove duplicates and empty lines?

Yes. Tick Remove duplicates and Remove empty items. Empty items are removed by default.

Is there a limit on list size?

There is no fixed limit. Very large lists depend on your browser memory, but tens of thousands of lines work normally.
