Hex to ASCII Converter

Paste hex to read it as text, or type text to get its hex bytes. UTF-8 safe, with decimal codes shown too.

How to convert hex to ASCII

Each pair of hex digits is one byte, and each byte maps to a character. Paste your hex, and spaces, commas and 0x or \x prefixes are ignored. For example:

48 65 6C 6C 6F → H(48) e(65) l(6C) l(6C) o(6F) = Hello

Tool names work the same way: 54 6F 6F 6C 50 6F 6E 64 reads as "ToolPond".

How the conversion works by hand

  1. Split the hex string into two-digit pairs.
  2. Convert each pair to decimal: 4×16 + 8 = 72 for 48.
  3. Look up decimal 72 in the ASCII table to find "H".

Standard ASCII covers codes 0–127. Letters, digits and punctuation are in the range 32–126; codes below 32 and 127 are control characters.

ASCII vs UTF-8

ASCII characters use one byte each. Characters outside ASCII, such as é or 日, use two to four bytes in UTF-8. This tool decodes the bytes as UTF-8, so ASCII text is unchanged while accented letters and symbols also work. For example, C3 A9 is the single character é.

Troubleshooting

  • Odd number of digits: every byte needs two hex digits, so write 0A, not A.
  • Strange symbols: the bytes may not be text (for example, an image or compressed data) or may use a different encoding.
  • Control characters: bytes below 20 hex are non-printable. The tool counts them for you.

Frequently asked questions

How do I convert hex to ASCII?

Split the hex into byte pairs, convert each pair to its decimal value, and look up the matching character. 48 65 6C 6C 6F becomes Hello. This tool does it automatically.

Does it accept 0x prefixes and spaces?

Yes. Spaces, commas, colons, dashes and 0x or \x prefixes are removed before decoding.

Can it convert text back to hex?

Yes. Choose Text → Hex, type your text, and pick a separator and uppercase or lowercase output.

What is the hex code for a space?

A space is 20 in hex, which is 32 in decimal.

Does it support UTF-8?

Yes. Input bytes are decoded as UTF-8, so accented letters and other non-ASCII characters convert correctly.
