About JSON Schema Generator

Generate a JSON Schema from sample JSON. The tool reads your example, works out the type of each value and writes a schema you can use to validate other data. It runs in your browser, so the JSON you paste is not uploaded anywhere.

How to use it

  1. Paste a representative JSON object or array into the left box.
  2. Choose whether every property found should be marked as required, and whether to add the $schema line (draft 2020-12).
  3. Click Generate Schema, then copy the result.

What it detects

Strings, whole numbers (integer), decimals (number), booleans, null, nested objects and arrays. For an array, the item type comes from the values in your sample. For example, {"name":"Ann","age":30,"tags":["a","b"]} produces a schema where name is a string, age is an integer and tags is an array of strings.

Limits to know about

  • A schema made from one sample only describes that sample. A value that is sometimes a string and sometimes a number needs editing by hand.
  • With "required" on, every property in the sample is required. Turn it off if some fields are optional in your real data.
  • It does not add rules such as minimum, maximum, patterns or formats. Add those yourself where you need them.

Frequently asked questions

What is JSON Schema used for? It describes the shape of JSON data so tools can check that an API request, a config file or a data export is valid before it is used.

Is my data sent to a server? No. The schema is generated by script in your browser.

Which draft does it use? The optional $schema line points to draft 2020-12. You can turn it off if your validator expects another draft.
